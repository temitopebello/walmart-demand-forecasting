# Dashboard

Power BI Desktop dashboard (`walmart_forecast.pbix`) is committed to this
folder in Sprint 4. The .pbix opens in Power BI Desktop (free) and surfaces:
- Forecast by store and department over the coming twelve weeks
- 95% prediction intervals
- Top-three feature attributions (SHAP) per forecast
- WMAE-by-store-tier fairness panel with 10% alert threshold
